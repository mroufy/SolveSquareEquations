### КОМПИЛЯЦИЯ  
Код программы для решения квадратных уравнений находится в *solve_sq_roots*.  
Чтобы скомпилировать программу и получить исполняемый файл, нужно скомпилировать файл `main.cpp` находящийся в папке code. Для компиляции рекомендуется ввести в командную строку  
`g++ code/main.cpp`  
Предварительно открыв папку *solve_sq_roots*

### ИСПОЛЬЗОВАНИЕ  
При вызове исполняемого файла через терминал после его названия можно написать команду, тем самым выбрав режим в котором будет работать программа, чтобы узнать о существующих режимах и о том какой командой их вызывать введите команду *help*  
Пример для исполняемого файла *a.out*:  
`a.out help`

Вот режимы в которых может работать программа:

- `study` - Режим обучения. Вы вводите коэффициенты квадратного уравнения, и ваша задача решить уравнение, в то время как программа проверяет ваши ответы

- `testauto` - запускает ранее написанные тесты, для проверки работоспособности программы

- `test <название файла>` - запускает тесты из файла с текстом, в котором они записаны (рекомендуется использовать в паре с testadd)

- `testadd <название файла>` - добавляет тесты в файл для дальнейшего использования с командой test

- `plot <название файла>` - рисует график квадратичной функции в текстовый файл (размеры графика не должны превышать ~40000x40000)

- `plotwobuf <название файла>` - рисует график сразу в файл, делает это медленнее, чем команда plot, но не ограничен по размерам (не рекомендуется для использования)

- либо можно ничего не вводить и тогда программа будет работать в режиме решения квадратных уравнений. Для решения программе нужны только коэффициенты уравнения, она выдаст корни уравнения
